# STA-556-Homework-2
Public Repository for STA 556 Homework 2

The data for this homework came from the UC Irving Repository for Machine Learning (https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset)

The data being used is the Bike Sharing data set that contains data on bike rental counts per day, along with data about the date, the weather (temp, windspeed, humidity), whether it is a holiday or not, and whether it is a workday or not.

The purpose of the project is to determine how the maximum temperature and whether the day given day is a workday affect bike rental counts.

To run the analysis, put the raw data in the data_raw folder. Then run all the code (in order) in the homework_2.ipynb notebook in python.
